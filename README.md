# NextBites — Kalvium Part 1

A responsive recipe homepage built with **Next.js App Router, React and TypeScript**.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Requirements
- Recipe data and exported `Recipe` type in `app/data/recipes.ts`
- Reusable typed `RecipeCard` component in `app/components/RecipeCard.tsx`
- Shared `NavBar` in `app/layout.tsx`
- Responsive recipe grid mapped with stable `recipe.id` keys in `app/page.tsx`

## Part 1 assignment
Development branch: `home-page` → base branch `main`.

Part 2 will add recipe search and dynamic detail routes; Part 3 will add deployment. No search or recipe detail pages are required for Part 1.
