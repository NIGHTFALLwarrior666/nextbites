# NextBites — Part 1: Repo Setup & Home Page

A responsive recipe homepage built with **Next.js App Router**, **TypeScript**, and a reusable `RecipeCard` component. Prepared for the Kalvium **5.1 Build a Project: NextBites | Repo Setup & Home Page** assignment.

## Features
- Typed `Recipe` model and eight sample recipes in `app/data/recipes.ts`
- Reusable `app/components/RecipeCard.tsx` with fully typed `recipe` prop (no `any`)
- Shared `NavBar` in `app/layout.tsx`
- `app/page.tsx` renders recipes with `recipes.map(...)` and stable `key={recipe.id}`
- Responsive CSS grid for phone, tablet and desktop
- Accessible headings, navigation, focus states and metadata

## Run locally

Install [Node.js](https://nodejs.org/) version **20.9 or newer**.

```bash
npm install
npm run dev
```

Open http://localhost:3000 . For a production check:

```bash
npm run typecheck
npm run build
```

> **Verification note:** Source files are prepared, but dependencies couldn't be fetched in the authoring environment. `npm install`, browser rendering, and `npm run build` must be run on a machine with access to the npm registry. The project was written to match a standard Next.js App Router scaffold; it was not generated by actually running `create-next-app` in the offline environment.

## Assignment repository and PR steps

The assignment requires a **new public GitHub repo**, a `main` scaffold commit, a `home-page` branch with the implemented homepage, and an **open Pull Request** into `main`. The ZIP alone is not the final assignment submission.

### Easiest: let the GitHub connector finish the PR

1. Visit https://github.com/new and create a **PUBLIC** repository called `nextbites` in your GitHub account.
2. **Check "Add a README file"** (this initializes the `main` branch).
3. Share the URL `https://github.com/YOUR_USERNAME/nextbites` in the ChatGPT conversation. With authorized GitHub access, the assistant can add the scaffold to `main`, create the `home-page` branch, upload the app source, and open the PR. It should verify the repo is public and avoid modifying any other repos.
4. Copy the real PR URL from GitHub into your Kalvium submission.

### Manual alternative

Follow `GITHUB_SUBMISSION_STEPS.md` if you prefer using Git and GitHub Desktop yourself. That guide provides a PowerShell workflow for creating a scaffold commit and feature branch.
